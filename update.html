Installing it

  1. Unzip the download. It holds a folder named arkivet2fs.
  2. Put its files over the folder this copy was loaded from (the extension's details page on chrome://extensions shows where that is). If you loaded a git clone, run git pull there instead.
  3. Reload the extension: the button below, or the reload button on its card. Your drafts and remembered persons are kept.

Settings

The check asks GitHub for the latest release. Nothing about you or your records is sent; GitHub sees only your IP address.
